How It Works

Three simple steps

From listing an item to getting it approved, the whole process is quick and easy.

1
List an Item

Add your item with images and details, then choose Borrow (free) or Rent (paid).

2
Find and Request

Browse or search for the item you need and send a request to the owner.

3
Get Approved

The owner approves your request and you use the item for the agreed time.

  • Choose how long you need the item
  • Owner approves your request
Rent

Paid for a set time

  • Price is set by the owner
  • Choose the rental duration
  • Same simple request process
